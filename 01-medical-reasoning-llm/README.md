# Medical Reasoning LLM

A portfolio project exploring medical reasoning in large language models using Qwen3-0.6B and parameter-efficient fine-tuning.

## Methods

- Qwen3-0.6B
- PyTorch
- Hugging Face Transformers
- PEFT / LoRA
- Medical reasoning dataset
- Baseline vs. post-training evaluation
- Error analysis
- Ablation studies
